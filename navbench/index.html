NAVBENCH

How do navigation policies trained on predictable layouts fail when they leave them — and how much would richer, real-environment behavioral data change that? A naive bug-style policy (forward, random-rotate-when-blocked, no planning) is run against procedurally generated rooms, each verified navigable before the episode starts.
